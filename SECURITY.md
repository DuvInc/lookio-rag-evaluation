# Security policy

Report privately through [GitHub security advisories](https://github.com/DuvInc/lookio-rag-evaluation/security/advisories/new) or the [maintainer's contact form](https://lookio.app/contact). Do not post sensitive material in a public issue.

This is a static research release with local validation scripts, maintained best-effort by one person. In scope: accidentally published secrets or private data, unsafe validation or generation code, and malicious archive/file paths. There is no deployed service or credential-bearing runtime in this repository.

Out of scope: model answer quality, third-party hosting and dependencies. Data or grading corrections belong in an ordinary issue without sensitive content. Untrusted downloaded documents should still be opened with maintained software.

If you fork this project, replace these reporting links with your own and review any additional data you publish. This policy does not transfer responsibility for your fork to the original maintainer.
